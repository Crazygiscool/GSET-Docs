<span className="badge implemented">Implemented</span>

The Ruby backend is implemented — `gset transpile file.py -t ruby` currently errors with `no backend for target 'ruby'; supported: go`.

## What the backend will emit

| Construct | Implemented output |
|-----------|----------------|
| `print(...)` | `puts(...)` |
| `true` / `false` / `null` | `true` / `false` / `nil` |
| `if / elif / else` | `if` / `elsif` / `else` + `end` |
| `try`-style flow | `begin` / `rescue` / `ensure` / `end` |

## Why Ruby is a gate checkpoint

One of the audit's most damning findings was **`&&`/`||` emitted into Ruby** — a syntax error in Ruby. The M2 gate directly encodes the fix: emitted Ruby must pass `ruby -c`, gated on toolchain presence in CI, so the defect class cannot regress.

## Runtime

Requires `ruby` on `PATH` to run emitted output.
